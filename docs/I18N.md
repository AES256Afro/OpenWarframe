# Other languages: design

**Status:** design only. The app, the exports and the reward helper work with English game
clients. This page is the plan for the rest.

## What breaks today

1. **Reward helper (OCR).** It reads item names from the reward screen and matches them against
   English names. A German client shows "Rhino Prime Systeme", which matches nothing.
2. **Name matching** strips non-ASCII letters, so names with accents (French, Spanish, Polish) or
   other scripts (Russian, Japanese, Korean, Chinese) can never match.
3. **The UI and exports** are written in English.

Everything driven by internal item paths (`/Lotus/...`) is language-independent already: the
profile, the inventory, drop tables and the world state. Only text a human or the OCR reads needs
translating.

## Where translated names come from

DE's Public Export is published per language: `index_<lang>.txt.lzma` for `en`, `de`, `es`,
`fr`, `it`, `ja`, `ko`, `pl`, `pt`, `ru`, `tc` (traditional Chinese), `th`, `tr`, `uk`, `zh`.
Each manifest has the same `uniqueName` keys with names in that language. So a translated name table
is one extra download, joined on `uniqueName`.

## Plan

1. **Name table.** `codex update --lang de` downloads the Public Export for that language and fills
   a new `item_name(unique_name, lang, name)` table. English stays in `item.name`. The game language
   comes from `EE.cfg` (`Language=`), with a setting to override it.
2. **Matching.** `live/match.py` normalizes with Unicode NFKC and case-folding instead of dropping
   non-ASCII, and matches against the table for the client's language. Part words ("Blueprint",
   "Systems", "Chassis", "Neuroptics") come from the same table, via the component items.
3. **OCR language.** Windows OCR and Apple Vision both take a language hint; pass the client's
   language, falling back to English when that OCR language pack isn't installed (say so in the
   reward helper rather than failing quietly).
4. **Display.** Item names in the app and exports follow a "Names in" setting (game language or
   English). Interface text stays English until there is a translator for a language; when there
   is, move strings to `static/i18n/<lang>.json`.
5. **Tests.** A small fixture per script family (German, Polish, Russian, Japanese) with OCR text
   and the expected match.

## Cost

About 30 MB extra per language in `codex.sqlite` if the per-item JSON is skipped (names only:
under 1 MB). One more download of about 4 MB per language on each game update.
